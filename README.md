## Reflektion kring Spring Boot
Spring Boot kräver mer att lära sig i början och ofta lite mer kod, 
men man får också många färdiga funktioner samt struktur på köpet.
För mindre projekt kan det dock kännas onödigt, 
men för större projekt känns det som en vinst eftersom koden blir 
tydligare och lättare att hålla ordning på, 
speciellt om man är flera i ett utvecklingsteam som arbetar med koden.

## Java/Spring Boot jämfört med Node.js/Express
En tydlig skillnad mellan Express och Spring Boot är att utvecklaren har 
större frihet att själv bestämma strukturen i Express.
Spring Boot har däremot fler färdiga lösningar och riktlinjer 
för hur projektet kan byggas upp.

Till exempel använder Spring Boot @RestController och 
@Service för att tydliggöra olika delars ansvar, 
medan det motsvarande i Express till större 
del bestäms av utvecklaren.
